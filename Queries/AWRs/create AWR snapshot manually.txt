CREATE_SNAPSHOT() function is used to create AWR snapshot manually. Below parameters can be passed in the function to capture the snapshots.
- flush_level (BESTFIT | LITE | TYPICAL | ALL)
- dbid
- source_name

Below are the flush levels:
BESTFIT :- Uses the default value depending on the type of snapshot being taken.
LITE or Lightweight:- Only the most important statistics are collected. This is default for a pluggable database (PDB) and application container.
TYPICAL or Regular :- Most of the statistics are collected. This is default for a container database root (CDB root) and non-CDB database.
ALL or Heavyweight :- All the possible statistics are collected. This consumes a considerable amount of disk space and takes a longer time to create.
