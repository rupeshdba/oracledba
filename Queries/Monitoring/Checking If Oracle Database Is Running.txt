#How to check if Oracle database is running or not

You can simply execute below command at OS level to check if Oracle database is running or not.

$ps -ef | grep pmon

OR

SQL> select instance_name,status from v$instance;

INSTANCE_NAME    STATUS
---------------- ------------
plugdb           OPEN

OR

If you want to check whether database is open in READ-WRITE mode, then you can execute below command.

SQL> select name,open_mode,controlfile_type,database_role from v$database;

NAME      OPEN_MODE            CONTROL DATABASE_ROLE
--------- -------------------- ------- ----------------
PLUGDB    READ WRITE           CURRENT PRIMARY
