lsattr in asmcmd lists the attributes of the ASM Disk group. Below attributes can be used with lsattr option.
-G diskgroup :- Disk group name.
--suppressheader :- Suppresses the column headings.
-l :- Display names with values.
-m :- Displays additional information, such as the RO and SYS columns.
pattern :- Display the attributes that contain pattern expression.

If you don't specify anything in lsattr command then, it will list only attribute names for all the disk groups.
